# Main-agent Prompt

`Yushi` defines agents via `main_prompt.md`. By meticulously designing the main agent's prompt, you can empower the agent to either work independently or coordinate sub-agents and utilize tools to accomplish more complex tasks.

Typically, a well-designed main agent combined with a thoughtfully curated set of tools can solve the majority of problems.

If you require the orchestration of sub-agents, the main agent must then evolve into a strategic planner and coordinator, rather than remaining merely a task executor.

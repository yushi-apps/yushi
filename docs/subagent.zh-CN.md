# 子代理

Yushi中的自定义子代理是专门的AI助手，可以被调用处理特定类型的任务。它们通过提供针对任务的定制化系统提示、工具以及独立的上下文窗口，从而更高效的解决问题。

## 什么是子代理

子代理是预先配置好的AI助手，智能体将任务委托给它们。每个子代理：
- 拥有特定的用途和专业领域
- 使用独立于智能体对话的上下文窗口
- 可以配置为仅使用特定的工具
- 包含一个定义的系统提示，用于引导其行为

当智能体遇到与某个子代理相匹配的任务时，它将任务委派给该子代理，子代理会独立运行并返回结果。

## 快速开始
```sh
cd my_agent
yushi agent new <agent_name>
```

会在`my_agent/.yushi/agents`目录下创建一个子代理定义文件。

### 文件格式

子代理定义文件是一个具有YAML前置内容的Markdown文件，文件结构如下所示：
``` yaml
---
name: 子代理名称
description: 说明在什么情况下应调用此子代理 
tools: tool1, tool2, tool3
---
在这里编写您的子代理的系统提示，可以是多个段落。
应该清晰地定义子代理的角色、能力和问题解决方法。
包括具体指令、最佳实践和子代理应遵循的任何约束。
```

#### 配置字段

| 字段 | 必需 | 描述 |
|----------|----------|----------|
|name|是|使用小写字母和下划线的唯一标识符|
|description|是|子代理能力的自然语言描述|
|tools|否|子代理使用的工具列表，多个工具用逗号分隔。|

#### 可用工具

子代理可以被授予访问`Yushi`任何内部工具的权限。有关可用工具的完整列表，请参阅[**工具文档**](./tool.md)。

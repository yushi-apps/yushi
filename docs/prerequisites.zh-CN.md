# 先决条件
Yushi使用Rust构建，要开始使用Yushi构建智能体，您首先需要安装一些依赖项。

## Linux和macOS

使用以下命令通过[Rustup](https://rustup.rs/)安装Rust：
```sh
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

## Windows

访问 https://rust-lang.net.cn/tools/install 以安装 `rustup`。

或者，您可以使用 `winget` 在 PowerShell 中使用以下命令安装 rustup

``` sh
winget install --id Rustlang.Rustup
```

请务必重新启动您的终端（在某些情况下是您的系统），以使更改生效。
